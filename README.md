## ✨ មុខងារសំខាន់ៗ

- **កាតាឡុកផលិតផល**: មើលកុំព្យូទ័រ ឡេបថប ដេស្កថប និងឧបករណ៍ជំនួយផ្សេងៗ
- **ការផ្ទៀងផ្ទាត់អ្នកប្រើប្រាស់**: ប្រព័ន្ធចុះឈ្មោះ និងចូលប្រើប្រាស់ដែលមានសុវត្ថិភាព
- **កន្ត្រកទំនិញ**: បន្ថែម/លុបផលិតផល និងកែប្រែចំនួនទំនិញ
- **ដំណើរការទូទាត់ប្រាក់**: ការភ្ជាប់ជាមួយប្រព័ន្ធទូទាត់ប្រាក់ ABA និង KhPay
- **ការគ្រប់គ្រងការបញ្ជាទិញ**: តាមដានប្រវត្តិ និងស្ថានភាពនៃការបញ្ជាទិញ
- **ប្រវត្តិរូបអ្នកប្រើប្រាស់**: គ្រប់គ្រងព័ត៌មានផ្ទាល់ខ្លួន និងលេខសម្ងាត់
- **ផលិតផលពេញចិត្ត**: រក្សាទុកផលិតផលដែលពេញចិត្តសម្រាប់មើលពេលក្រោយ
- **ផ្ទាំងគ្រប់គ្រងសម្រាប់ Admin**: គ្រប់គ្រងផលិតផល ការបញ្ជាទិញ អ្នកប្រើប្រាស់
- **ការជូនដំណឹងតាមអ៊ីមែល**: បញ្ជាក់ការបញ្ជាទិញតាមរយៈ PHPMailer
- **ការផ្ទៀងផ្ទាត់លេខ OTP**: ការផ្ទៀងផ្ទាត់ប្រកបដោយសុវត្ថិភាពសម្រាប់ប្រតិបត្តិការស្ថាបនា
- **ការរចនាបែប Responsive**: ផ្ទៃកម្មវិធីដែលប្រែប្រួលតាមទំហំអេក្រង់ទូរស័ព្ទ ឬកុំព្យូទ័រ
- **ការបង្កើតវិក្កយបត្រ**: បង្កើតវិក្កយបត្របាទឌីជីថលសម្រាប់ការបញ្ជាទិញ

## 🔧 បច្ចេកវិទ្យាដែលប្រើប្រាស់

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Backend**: PHP 7+
- **Database**: MySQL
- **Email**: PHPMailer
- **Payment Gateways**: ABA Bank, KhPay
- **Security**: Password hashing, OTP verification

## 📝 ការដំឡើង និងការកំណត់

### ជំហានទី 1: ក្លូនឯកសារ Repository

```bash
git clone https://github.com/masterM2324/computer_shop.git
cd computer_shop
```

### ជំហានទី 2: ឆ្នើមផ្ទាំង localhost

```bash

cp -r computer_shop C:\xampp\htdocs\

cp -r computer_shop C:\wamp\www\
```

1. បង្កើត Database ឈ្មោះថា `computer_shop`

## 💾 ការកំណត់រចនាសម្ព័ន្ធ Database

កែប្រែឯកសារ `db/db.php` ដូចខាងក្រោម៖

```php
<?php
$host = "localhost";
$user = "root";
$password = ""; // រក្សាទុកលេខសម្ងាត់របស់អ្នក
$dbname = "computer_shop";

$conn = new mysqli($host, $user, $password, $dbname);

if ($conn->connect_error) {
    die("Connection failed: " . $conn->connect_error);
```
