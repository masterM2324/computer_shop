## ✨ មុខងារសំខាន់ៗ

- **កាតាឡុកផលិតផល**: មើលកុំព្យូទ័រ ឡេបថប ដេស្កថប និងឧបករណ៍ជំនួយផ្សេងៗ
- **ការផ្ទៀងផ្ទាត់អ្នកប្រើប្រាស់**: ប្រព័ន្ធចុះឈ្មោះ និងចូលប្រើប្រាស់ដែលមានសុវត្ថិភាព
- **កន្ត្រកទំនិញ**: បន្ថែម/លុបផលិតផល និងកែប្រែចំនួនទំនិញ
- **ដំណើរការទូទាត់ប្រាក់**: ការភ្ជាប់ជាមួយប្រព័ន្ធទូទាត់ប្រាក់ ABA និង KhPay
- **ការគ្រប់គ្រងការបញ្ជាទិញ**: តាមដានប្រវត្តិ និងស្ថានភាពនៃការបញ្ជាទិញ
- **ប្រវត្តិរូបអ្នកប្រើប្រាស់**: គ្រប់គ្រងព័ត៌មានផ្ទាល់ខ្លួន និងលេខសម្ងាត់
- **ផលិតផលពេញចិត្ត**: រក្សាទុកផលិតផលដែលពេញចិត្តសម្រាប់មើលពេលក្រោយ
- **ផ្ទាំងគ្រប់គ្រងសម្រាប់ Admin**: គ្រប់គ្រងផលិតផល ការបញ្ជាទិញ អ្នកប្រើប្រាស់ និងសារទំនាក់ទំនង
- **ការជូនដំណឹងតាមអ៊ីមែល**: បញ្ជាក់ការបញ្ជាទិញតាមរយៈ PHPMailer
- **ការផ្ទៀងផ្ទាត់លេខ OTP**: ការផ្ទៀងផ្ទាត់ប្រកបដោយសុវត្ថិភាពសម្រាប់ប្រតិបត្តិការសំខាន់ៗ
- **ការរចនាបែប Responsive**: ផ្ទៃកម្មវិធីដែលប្រែប្រួលតាមទំហំអេក្រង់ទូរស័ព្ទ ឬកុំព្យូទ័រដោយប្រើ Bootstrap
- **ការបង្កើតវិក្កយបត្រ**: បង្កើតវិក្កយបត្រឌីជីថលសម្រាប់ការបញ្ជាទិញ
